# Scratch More MakeCode-Erweiterung

Dies ist eine MakeCode-Erweiterung für [Scratch More v2](https://calliope-edu.github.io/Scratch-more-v3).
Die Originalversion findest du hier: https://github.com/microbit-more/pxt-mbit-more-v2

## Verwendung als Erweiterung

Dieses Repository kann als **Erweiterung** in MakeCode hinzugefügt werden.

1. Öffne [https://makecode.calliope.cc](https://makecode.calliope.cc)
2. Klicke auf **Neues Projekt**
3. Klicke im Zahnrad-Menü auf **Erweiterungen**
4. Suche nach [https://github.com/calliope-edu/pxt-more-v2](https://github.com/calliope-edu/pxt-Scratch-more/) und importiere es
5. Programmieren im Editor
6. Klicke auf **Download** (die erste Kompilierung dauert etwa **1 Minute**)

# Scratch More MakeCode Extension

This is a MakeCode extension for [Scratch More V3](https://calliope-edu.github.io/Scratch-more-v3).
Original version can be found here: https://github.com/microbit-more/pxt-mbit-more-v2

## Use as Extension

This repository can be added as an **extension** in MakeCode.

* open [https://makecode.calliope.cc](https://makecode.calliope.cc)
* click on **New Project**
* click on **Extensions** under the gearwheel menu
* search for **[https://github.com/calliope-edu/pxt-more-v2](https://github.com/calliope-edu/pxt-Scratch-more/)** and import
* code on the editor
* click **Download** (which takes about **1 minutes** to compile at first time)
